# Jinsung Kim — Web Programming Portfolio

Course portfolio project using HTML / CSS / JavaScript / CSV.
Project information is loaded from `works.csv` with JavaScript and rendered dynamically.

## Local preview

Because the site loads `works.csv` with `fetch()`, do not open `index.html` directly with `file://`.

```bash
cd web-programming-portfolio
python3 -m http.server 8000
```

Then open: http://localhost:8000

Or use VS Code Live Preview / Live Server.

## GitHub Pages

Publish the repository from **Settings → Pages → Deploy from a branch → main / root**.
